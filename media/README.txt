Put your images, videos and PDFs in this folder.

- Sub-folders become groups in the library (e.g. media/Sales, media/Events).
- Optional title: add a text file with the same name plus ".txt"
  (media/Sales/q3.pdf  ->  media/Sales/q3.pdf.txt, first line = title).
- Files or folders starting with "." or "_" are ignored.
- Supported: jpg, png, gif, webp, avif, svg, mp4, webm, mov, pdf.
